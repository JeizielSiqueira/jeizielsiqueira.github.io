Política de Privacidade

Versão inicial: 30 de outubro de 2026.

Esta política descreve a operação atual do Agente Jurídico — Inteligência, um software independente de uso controlado para pesquisa de fontes jurídicas brasileiras e cópias de segurança de sua própria base de pesquisa.

1. Responsável e contato

O projeto é mantido pelo titular da conta JeizielSiqueira. Para solicitações gerais, utilize o canal público do projeto, sem inserir dados pessoais, informações processuais confidenciais ou credenciais. Para questões privadas, utilize o e-mail de suporte informado na tela de consentimento OAuth.

2. Dados e permissões solicitados

O programa solicita autorização OAuth para a API Google Drive com o escopo https://www.googleapis.com/auth/drive. Esse escopo é amplo: tecnicamente, permite visualizar, criar, modificar e excluir arquivos no Drive da conta autorizada, conforme as permissões efetivas da conta. A autorização não é restrita tecnicamente à pasta configurada.

Na versão atualmente implantada, a rotina automática utiliza a pasta de trabalho designada pelo operador: lista arquivos dessa pasta, baixa snapshots e manifestos para restauração, e envia novos bancos SQLite, relatórios, manifestos de integridade e eventuais evidências documentais. A aplicação não foi concebida para varrer todo o Drive nem distribuir arquivos fora dessa finalidade.

3. Finalidades e uso dos dados

  • Restaurar a base jurídica de uma execução anterior, conferindo a integridade dos arquivos por hash.
  • Persistir alterações e resultados das pesquisas em backups versionados.
  • Produzir registros de execução, diagnóstico e auditoria das fontes utilizadas.

A pesquisa de novidades jurídicas usa fontes públicas institucionais. O conteúdo privado do Google Drive não é enviado a modelos de inteligência artificial pelo fluxo diário atualmente publicado; se futuramente houver integração desse tipo, a política deverá ser atualizada e será necessária a autorização pertinente.

4. Armazenamento, segurança e compartilhamento

As cópias de segurança permanecem na pasta Google Drive do usuário. Durante as execuções agendadas, o software processa temporariamente uma cópia em um ambiente de execução do GitHub Actions. Os tokens OAuth ficam no ambiente local do operador ou nos segredos de configuração do GitHub Actions; não são publicados no site. Dados e registros necessários ao funcionamento são processados pelos provedores Google e GitHub conforme seus serviços.

O projeto não comercializa dados pessoais nem usa dados do Drive para publicidade. Arquivos da base, backups e documentos privados não são disponibilizados no repositório público deste site. Não há compartilhamento deliberado desses dados com terceiros para fins alheios à operação descrita.

5. Conservação e exclusão

Os backups versionados permanecem no Google Drive até exclusão pelo titular ou por rotina de retenção que venha a ser expressamente configurada. A versão atual não executa exclusão automática dos backups antigos. O operador pode remover os arquivos na pasta do Drive e interromper as execuções do GitHub Actions.

6. Revogação e direitos do titular

O acesso pode ser revogado nas configurações de segurança da conta Google, em Conexões com apps e serviços de terceiros. Revogar a autorização impede novas operações, mas não apaga automaticamente cópias que já estejam armazenadas; elas precisam ser excluídas separadamente. Solicitações relativas a dados pessoais podem ser dirigidas ao responsável pelo projeto, sem publicar informações sensíveis em canais públicos.

7. Site público e alterações

Este site contém apenas informações institucionais. O serviço de hospedagem GitHub Pages pode registrar dados técnicos de acesso, conforme suas próprias políticas. Esta política será revisada se forem acrescentadas finalidades, destinatários ou permissões. A data da atualização será identificada nesta página.
